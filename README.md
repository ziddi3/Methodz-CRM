# Methodz-CRM

A custom CRM built for Methodz to manage new leads, potential clients, and partner cross-sell opportunities from one place.

## Features

- Create, edit, and delete contacts
- Track each contact as a new lead, potential client, or active client
- Capture service interest, next steps, and notes
- Suggest partner follow-up services for cross-sell opportunities
- Persist data in the browser with local storage

## Running the CRM

This project is a lightweight static app with no build step.

Open `/home/runner/work/Methodz-CRM/Methodz-CRM/index.html` directly in a browser, or serve the repository root with a static file server such as:

```bash
cd /home/runner/work/Methodz-CRM/Methodz-CRM
python3 -m http.server 8000
```
